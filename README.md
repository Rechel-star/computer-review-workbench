# 知序 · 华电计算机类新大纲复习工作台

依据《华电集团笔试大纲(1).pdf》计算机类专业版重建，10个方向、48个大纲条目，专业70%、通用30%。提供198个教学知识点和198道原创配套判断例题；公共与行业固定原题另行保留563道，前500道为默认范围。

## 使用

打开 index.html，保留 styles.css、theme.css、content.js、app.js 在同一目录。无需安装、注册或后端服务，也不依赖外部资源。

计算机知识每节对应一个大纲条目，支持阅读标记、逐点判断解析和本节独立自测。固定题支持背诵（显示答案）、独立自测（交卷前隐藏答案）、即时解析三种模式，可按原题范围、题型、分类和进度筛选。

固定题1—245为单选，246—426为多选，427—563为判断。默认前500题包含245单选、181多选、74判断；额外63题完整保留。多选支持多个选择，本工作台完整匹配计对，每题1分仅用于练习。

## 学习记录

阅读、已背、答题、错题、收藏、笔记和当前背练位置保存在当前浏览器，可在“记录管理”导出和导入。电脑与平板不自动同步。本版使用新的存储键，不修改旧版学习记录。
