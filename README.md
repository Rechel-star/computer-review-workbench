# 知序 · 计算机复习工作台

基于v4逐知识点内容的独立静态工作台。原五板块各200题保留；另有331道知识点补充例题，合计1331个不同题号。1115条教学说明每条都有对应例题；条目含复习重叠，不表示完全独立知识点。没有账号注册和后端依赖，不调用外部网络资源。

## 使用

推荐打开工作区根目录的“计算机复习工作台.html”。这个单文件包含页面、样式、程序和完整知识内容，复制到其他位置也可以使用。

也可以打开本目录的index.html，保留app.js、styles.css、content.js在同一目录。若需要本地HTTP服务：

```bash
python3 -m http.server 8793 --bind 127.0.0.1 --directory "/Users/bytedance/Library/Application Support/LarkShell/Study_platform/exam-workbench"
```

打开 http://127.0.0.1:8793 。

## 功能

- 总览：已读专题、练习题量、当前正确率、错题与每日目标。
- 知识图谱：46个基础小节和221个细分及详细补充专题，完整阅读、已读标记、专题题目、来源索引。
- 逐点例题：每条知识下直接四选一作答、提交解析、再做一次、收藏和笔记，错题加入统一错题本。
- 详细补充：本轮新增100条知识，每条含定义、机制、具体场景和易混区别。
- 章节练习：顺序练习、未做题、随机抽题与本章错题，20/50/整章200题。
- 专题练习：从知识页进入对应题目，提交后显示答案和解析。
- 随机自测：20/50/100题，全范围均衡或指定板块，支持不限时或20/40/60分钟。
- 自测恢复：选择自动保存，未交卷不显示答案，到时自动交卷。
- 错题本：按最近一次已提交答案整理；重做正确自动移出。
- 收藏与笔记：每道题可以收藏，解析处笔记自动保存。
- 搜索：标题、讲义正文、术语、题干与题号，最多先显示50项结果。
- 记录管理：导出和导入JSON，导入前确认替换，清空前确认。
- 桌面与移动布局，原生按钮键盘访问、焦点提示和减少动画适配。

## 保存与计分

记录保存在当前浏览器localStorage。浏览器、网址和本地文件位置改变时，记录可能分别存储，请定期导出。没有云同步；清除浏览器数据也会清除记录。若浏览器禁止本地保存，会提示导出备份。

每题1分、不倒扣，仅为工作台练习规则，不是官方考试规则。已读仅代表阅读完成，不等于掌握。总览正确率按每道题最近一次已提交答案统计，练习用时包含本次会话离开页面的时间。

自测未答题不计入错题本，交卷后在结果页“重做错题与未答题”补练。一个时点保留一组可恢复练习，开始新组会在必要时确认替换；历史成绩及已提交的答题保留。

## 内容边界

只对应截图中的五类专业知识，截图之外30%尚未提供。拓展标记、资料阅读状态和原题解析沿用v3内容；不承诺穷尽所有命题。基础题回链小节，新增题还关联具体知识条目。

## 文件

- index.html：页面入口。
- styles.css：自适应样式。
- app.js：路由、学习记录和答题流程。
- content.js：完整v4内容，保留原题及原条目编号，新增例题有独立编号。

个人记录单独保存，不写回题库。无需安装Node或前端包。
